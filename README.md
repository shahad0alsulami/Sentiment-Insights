# Sentiment Insights

## Graduation Project | 2026

## Project Overview
Sentiment Insights is an AI-powered application designed to analyze customer feedback using Natural Language Processing (NLP) and Machine Learning.

The system classifies text into Positive, Negative, and Neutral sentiment categories and presents analytical results to support decision-making.

## Technologies
- Python
- Flask REST API
- Flutter
- Firebase Authentication and Firestore
- Natural Language Processing (NLP)
- Machine Learning

## Key Features
- User authentication
- CSV file upload
- Sentiment classification
- Sentiment distribution visualization
- Analysis history

## Model Performance
The sentiment classification model achieved 89.47% accuracy on the test dataset.

## Project Goal
Help businesses and users understand customer opinions and extract meaningful insights from text data.
